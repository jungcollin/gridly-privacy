Gridly 개인정보처리방침

시행일: 2026년 5월 8일

Gridly는 사용자의 개인정보를 수집, 전송, 판매 또는 공유하지 않습니다.

Gridly는 브라우저 안에서만 동작하며, 사용자가 선택하거나 현재 페이지에서 감지된 그리드 형태의 영역에 레이아웃 변경을 적용합니다. Gridly는 페이지 내용, 방문 기록, 계정 정보, 개인 식별자 또는 YouTube 계정 정보를 개발자 서버나 외부 서버로 전송하지 않습니다.

저장되는 데이터

Gridly는 사용자의 레이아웃 설정만 Chrome storage.sync에 저장합니다. 저장될 수 있는 설정은 다음과 같습니다.

  • Gridly 사용 여부
  • 한 줄에 표시할 항목 수
  • 반응형 설정
  • 최소 카드 너비
  • 항목 간격
  • Shorts 처리 방식
  • 적용 범위: 현재 페이지, 페이지 패턴 또는 전체 사이트
  • 사용자가 입력하거나 선택한 CSS 선택자

이 설정은 사용자가 선택한 범위에 맞는 페이지를 다시 방문했을 때 같은 레이아웃을 적용하기 위해서만 사용됩니다.

권한 사용

  • activeTab: 사용자가 확장 프로그램을 조작한 현재 탭에 레이아웃 변경을 적용하기 위해 사용합니다.
  • storage: 페이지, 페이지 패턴 또는 사이트별 설정을 저장하기 위해 사용합니다.
  • scripting: 이미 열려 있는 탭에 content script가 준비되지 않은 경우 Gridly를 주입하기 위해 사용합니다.
  • content scripts: 그리드 컨테이너를 감지하고 CSS 레이아웃 변경을 로컬에서 적용하기 위해 사용합니다.

외부 서비스

Gridly는 원격 서버, 분석 도구, 광고 SDK, 추적 픽셀 또는 제3자 데이터 처리 서비스를 사용하지 않습니다.

데이터 삭제

사용자는 Gridly 팝업의 현재 범위 초기화 또는 전체 초기화 기능으로 저장된 설정을 삭제할 수 있습니다. Chrome에서 Gridly를 제거하면 확장 프로그램 데이터도 삭제됩니다.

문의

지원 또는 개인정보 관련 문의는 Chrome 웹 스토어 등록정보에 표시된 개발자 이메일로 연락해 주세요.
